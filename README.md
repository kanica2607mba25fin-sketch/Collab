# 📊 Financial AI & Risk Analytics Labs

A collection of AI, Machine Learning, and Responsible AI labs focused on Finance, Risk Analytics, Fraud Detection, Explainable AI, and Ethical AI using Google Colab notebooks.

This repository demonstrates practical implementation of AI concepts in real-world financial industry use cases.

# 🚀 Project Overview

This repository contains multiple hands-on labs covering:

- 💳 Credit Risk Analytics
- 📈 Financial Risk Prediction
- 🚨 Fraud Detection Analytics
- ⚖️ Bias Detection in Loan Approval
- 📊 Fairness Metrics Evaluation
- 🔍 Explainable AI using SHAP & LIME
- 🛡️ Ethical Risk Assessment
- 🔎 Transparency & AI Auditing

The labs are implemented using Python and Google Colab notebooks for easy experimentation and learning.
